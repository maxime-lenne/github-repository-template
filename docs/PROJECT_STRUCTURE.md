# Project Structure

```text

├── bun.lock                    # Bun lock file

├── package.json                # Project configuration
├── release.config.js           # semantic-release configuration
├── renovate.json               # Renovate configuration
├── CHANGELOG.md                # Generated by semantic-release
├── CLAUDE.md                   # AI assistant entry point
```

## Configuration Files

### Project Configuration

| File | Purpose |
|------|---------|
| `package.json` | Dependencies, scripts, project metadata |
| `bun.lock` | Locked dependency versions |
| `.gitmoji.json` | Gitmoji-cli configuration |

### Code Quality

| File | Purpose |
|------|---------|
| `.markdownlint.json` | Markdown linting rules |
| `.yamllint.yml` | YAML linting rules |
| `.editorconfig` | Editor settings |
| `commitlint.config.js` | Commit message validation (gitmoji or conventional) |

### CI/CD

| File | Purpose |
|------|---------|
| `.github/workflows/lint.yml` | Lint on push/PR |
| `.github/workflows/release.yml` | Release on merge into `main` |
| `.github/workflows/init.yml` | Bootstrap of a repository created from the template |
| `.github/workflows/setup.yml` | Apply `.github/settings.yml` (manual, `ADMIN_TOKEN`) |
| `.github/settings.yml` | GitHub settings as code |
| `release.config.js` | semantic-release configuration |
| `renovate.json` | Automatic dependency updates (Renovate) |

### Git Hooks

| Directory | Purpose |
|-----------|---------|
| `.husky/` | Git hooks managed by Husky |

## GitHub Configuration (`.github/`)

### Workflows

- **`lint.yml`** - Runs all linters on push/PR
- **`release.yml`** - semantic-release when a PR is merged into `main`
- **`init.yml`** - One-shot bootstrap on the first push of a new repository
- **`setup.yml`** - Applies `settings.yml` with an `ADMIN_TOKEN` secret

### Issue Templates

- **`bug_report.yml`** - Bug report template
- **`feature_request.yml`** - Feature request template
- **`config.yml`** - Issue template configuration

### Pull Request

- **`pull_request_template.md`** - PR template
